# 🥊 Raebareli Boxing & Combat Academy (Ironclad India)

> High-performance championship boxing academy, sanctioned title series, and combat training platform built with React, Vite, and Tailwind CSS.

---

## 🌟 Key Features

* **Bharat Grand Prix Championship Series**: Sanctioned professional bouts (WBC India & Indian Boxing Council).
* **Interactive 8-Man Tournament Bracket**: Follow the knockout roadmap from Quarter-Finals to the Championship Grand Final.
* **Tale of the Tape Biometric & AI Predictor**: Compare reach, height, punching power, hand speed, and algorithmic fight simulation probabilities.
* **Virtual Combo Coach & 3-Min Round Timer**: Practice orthodox combinations with interactive punch sounds and round bell rings.
* **Ringside Tickets & PPV Booking**: Real-time pass calculator with INR (₹) pricing, GST breakdown, and digital fight pass issuance.
* **Fighter Sanctioning & Entry License**: Digital athlete registration portal generating verified commission passes.
* **Full Weekly Timetable & Academy Curriculum**: Schedule slots for heavy bag conditioning, youth golden gloves, and pro contender sparring.

---

## 🛠️ Technology Stack

* **Frontend**: React 19, Vite
* **Styling**: Tailwind CSS, Vanilla CSS, Lucide Icons
* **Animations**: Framer Motion, Canvas Confetti
* **Audio Engine**: Web Audio API Sound Synthesizer (Boxing Bell & Glove Impact)

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Local Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 3. Build for Production
```bash
npm run build
```
